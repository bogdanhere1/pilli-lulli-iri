# Пилли и Люлли: чек-лист заявки в ИРИ

Общий чек-лист команды ЁжKino для подачи сериала «Пилли и Люлли» на конкурс АНО «ИРИ» «Национальный контент», направление «Видеоконтент».

Страница открывается через GitHub Pages. Вход по одному общему паролю. Все пункты, статусы и заметки хранятся в Supabase и видны только после входа. В репозитории лежит только код страницы.

## Настройка (один раз, около 10 минут)

1. Зайти на supabase.com, создать бесплатный проект (регион Europe, например Frankfurt).
2. **SQL Editor → New query**: вставить содержимое файла `supabase_setup.sql` (присылается отдельно, в репозиторий не кладётся) и нажать **Run**. Это создаст таблицу, закроет её от неавторизованных и загрузит 49 пунктов.
3. **Authentication → Users → Add user → Create new user**: почта, например `iri@ezkino.pro`, и общий пароль для команды. Галочку «Auto Confirm User» включить.
4. **Authentication → Sign In / Providers → Email**: выключить «Allow new users to sign up», чтобы никто не мог завести свой аккаунт.
5. **Project Settings → API**: скопировать **Project URL** и ключ **anon / publishable**.
6. В `index.html` заполнить три строки в блоке «Настройки»: `SUPABASE_URL`, `SUPABASE_ANON_KEY`, `TEAM_EMAIL` (почта из шага 3).
7. **Settings → Pages** в этом репозитории: Source — `Deploy from a branch`, ветка `main`, папка `/ (root)`.

Коллегам отправить ссылку на страницу и пароль.

## Что важно знать

- Ключ `anon` публичный по устройству Supabase, его можно хранить в коде. Данные защищает пароль: без входа таблица не читается и не меняется.
- Секретный ключ `service_role` никогда не вставлять в страницу.
- Пароль меняется в Supabase: **Authentication → Users → пользователь → Reset password / Update**. Старый пароль сразу перестаёт работать для новых входов.
- Аккаунт общий, поэтому каждый вписывает своё имя в поле «Вы отмечаете как». Оно подписывает изменения.
- GitHub Pages для приватного репозитория доступен на платных тарифах GitHub. На бесплатном тарифе репозиторий нужно сделать публичным. Содержимое чек-листа при этом остаётся закрытым паролем.
